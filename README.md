# Gemini MCP Standalone App

This is a standalone, full-stack application featuring a React frontend and a Node.js/Express backend. This architecture allows for secure management of API keys, handling of complex, server-side tool logic, and persistent storage with a PostgreSQL database.

## Quickstart Guide

Follow these steps to get the application running correctly in your local test environment.

### Prerequisites

You must have [Node.js](https://nodejs.org/) (which includes `npm`) and [PostgreSQL](https://www.postgresql.org/download/) installed and running on your computer.

### Step 1: Install Dependencies

Open a terminal (like Command Prompt, PowerShell, or your IDE's built-in terminal) in the project's root directory and run the following command to install all necessary packages:

```bash
npm install
```

### Step 2: Set Up Your Environment File

The backend server requires your Google Gemini API key and database connection details to function.

1.  Create a new file named `.env` in the root directory of the project. You can use the `.env.example` file as a template.
2.  Add your API key and database connection details to this file.

```
# === API KEYS ===
# Your secret Google Gemini API Key
API_KEY=AIzaSy...your...secret...key...here

# === SERVER CONFIG ===
# The port the backend server will run on (optional, defaults to 3001)
PORT=3001

# === POSTGRESQL DATABASE CONNECTION ===
PG_USER=your_postgres_username
PG_HOST=localhost
PG_DATABASE=your_database_name
PG_PASSWORD=your_postgres_password
PG_PORT=5432
```

**Important:** Never share your `.env` file or commit it to version control. It is listed in `.gitignore` to prevent this.

### Step 3: Run the Application

This application has two parts that must be running at the same time: the **backend server** and the **frontend client**. You will need to open **two separate terminals** for this.

**Terminal 1: Start the Backend Server**

In your first terminal, run this command to start your local server:

```bash
npm run server
```

You should see messages confirming `Server listening at http://localhost:3001` and `Database table "images" is ready.`. Keep this terminal running. The server will automatically create an `uploads` directory in your project root to store images generated by the Image tool.

**Terminal 2: Start the Frontend Client**

In your second terminal, run this command to serve the frontend UI:

```bash
npm run client
```

This command will serve the frontend files and should provide you with a local address to open in your web browser (e.g., `http://localhost:8080` or similar).

Once both parts are running, the application will be fully functional. You can now test your standalone multi-tool AI app!
